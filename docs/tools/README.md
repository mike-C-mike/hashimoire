# Tools

This folder contains tool-specific notes for DFIR and defensive security work.

These notes are for installation details, usage reminders, workflow gotchas, command examples, validation notes, and practical field references for specific tools.

Tool notes should stay focused on the tool itself.

Broader process notes belong in `docs/evidence-workflows/`.

Quick command refreshers belong in `snippets/`.

Repeatable step-by-step procedures belong in `playbooks/`.
