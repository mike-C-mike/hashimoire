# Save Hashimoire to a Phone Home Screen

**Use case:** field readiness | quick reference  
**Environment:** ios | android  
**Risk:** safe

Hashimoire is a website that can be opened from a phone home-screen icon, giving field collectors a one-tap path to current published guidance without installing an app-store package.

## iPhone / iPad — Safari

1. Open [Hashimoire](https://mike-C-mike.github.io/hashimoire/) in **Safari**.
2. Tap **Share** (depending on the layout, this may be inside the page menu).
3. Choose **Add to Home Screen**.
4. Enable **Open as Web App** if the option appears.
5. Name it **Hashimoire** and tap **Add**.

## Android — Chrome

1. Open [Hashimoire](https://mike-C-mike.github.io/hashimoire/) in **Chrome**.
2. Tap the **⋮** menu.
3. Choose **Add to Home screen** or **Install app** (the label depends on Chrome/device).
4. Confirm the name **Hashimoire**.

## Operational limits

- **Internet connection required.** This version uses an online Markdown renderer and external JavaScript dependencies. A home-screen shortcut is **not** a guaranteed offline reference.
- The icon may launch as a standalone web-app window on supported devices, or open in the browser on others.
- Agency-managed devices may block home-screen installations or restrict external websites.
- Treat this as a convenience reference, not an agency-approved procedure. Follow training, chain-of-custody requirements, and applicable legal authority.
- Verify relevant guidance before relying on it in the field, especially if a device or OS behaves differently than documented.
- Do not enter evidence, case identifiers, passwords, recovery keys, or protected information into this public reference website.
