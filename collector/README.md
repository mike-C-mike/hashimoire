## First principles

- **Confirm scope and authority.** Know what is being collected and why.
- **Photograph before interacting.** Preserve original position, cables, screen, damage, and surrounding context.
- **Document whether it is on, off, locked, or unlocked.** Do not assume a dark screen means powered off.
- **Do not explore the device.** Browsing files, opening apps, or guessing passwords can change evidence.
- **Call an examiner early** if encryption, remote wipe, damage, or an unusual configuration could change how the device should be collected.

## What this guide is not

The collector section intentionally avoids advanced device exploitation, extractions, malware interpretation, and forensic command execution. Those belong in the [Examiner Toolkit](/examiner/README.md).
